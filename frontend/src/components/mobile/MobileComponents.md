# Companion Document: Mobile AI & PWA Components

## Component Suite Overview

### 1. `OfflineBanner.jsx`
- **Responsibility**: Top sticky alert bar showing red "Offline Mode" banner when disconnected, and transitioning to an emerald green "Connection restored" confirmation when network returns.
- **Data Flow**: Subscribes to `useOnlineStatus` hook (`isOnline`, `wasOffline`).

### 2. `MobileAIBottomNav.jsx`
- **Responsibility**: First-class mobile bottom navigation bar on screens under 768px (`Home`, `AI Copilot`, `Agents`, `Alerts`, `Menu`).
- **Features**: Elevated central AI Copilot action button, notification badge counters, safe-area inset padding.

### 3. `MobileDailyBriefing.jsx`
- **Responsibility**: Displays critical attention items (Critical cases, High-priority borrowers, Ready reconciliations, Total overdue) with a sequential interactive "Priority Review" workflow.

### 4. `MobileAgentCenter.jsx`
- **Responsibility**: Responsive 1-column card list for monitoring, running, and inspecting all 6 autonomous operational agents with offline protection.

### 5. `MobileAgentRunTimeline.jsx`
- **Responsibility**: Mobile timeline inspector detailing rule-based pre-checks, database fact extractions, Groq token counters, execution durations, and audit log verifications.

### 6. `MobileAIInsightCard.jsx`
- **Responsibility**: Displays collection efficiency, active exposure, overdue balance, and month-over-month trend percentages generated by Agent 5.

### 7. `MobileAIActionCard.jsx`
- **Responsibility**: Human-in-the-Loop action proposal card (`FLAG_CASE`, `ASSIGN_CASE`, `DRAFT_REMINDER`, `OVERRIDE_MATCH`) with tactile haptic feedback on Confirm / Dismiss.

### 8. `MobileAIContextHeader.jsx`
- **Responsibility**: Active entity badge with contextual shortcuts (`[Explain]`, `[Investigate]`, `[Re-analyze]`, `[Escalate]`).

### 9. `MobileAIActivityFeed.jsx`
- **Responsibility**: Chronological timeline of multi-agent activities with one-tap deep investigation triggers.
